# LLM Interaction Logs

This folder contains the LLM interaction logs generated during the development and testing of Tax Notice Triage.

## Included Sessions

1. `session1-build.jsonl` – Conversation logs covering the initial problem exploration, solution design, architecture decisions, and prototype development.
2. `session2-appendix.jsonl` – Follow-up interactions covering testing, refinements, edge cases, and failure analysis.

## Purpose

These logs demonstrate how the LLM was used throughout the project, including:
- Problem exploration and research
- Prompt development and refinement
- Architecture and workflow design
- Testing and debugging
- Analysis of limitations and failure cases

The final decisions and implementation were reviewed and controlled by the human developer.
